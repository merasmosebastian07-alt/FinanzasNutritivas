# Finanzas Nutritivas

Sitio web comercial de Finanzas Nutritivas, construido con Next.js, TypeScript y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Calidad

```bash
npm run typecheck
npm run lint
npm run build
```

## Logo

El archivo oficial está en `public/brand/logo.jpeg`. Para usarlo en el header y el footer, no se rediseña ni se recorta en círculo.
